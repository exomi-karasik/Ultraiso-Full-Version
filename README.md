## ⚡ Key Features
<a id="key-features"></a>

### Core Functionality:
- **Edit ISO Images** — Directly modify the content of your ISO files.
- **Extract Files** — Easily extract files from existing ISO images.
- **Folder Management** — Add, remove, or create new folders within an ISO image.
- **Image Creation** — Create ISO images from documents on your hard drive or from audio discs.
- **Boot Information** — Manage boot information on disc images.

- **ISO 9660 Levels** — Supports ISO 9660 standards at levels 1, 2, and 3.
- **Compatibility** — Works seamlessly on both modern and older PCs, including Windows 98.
